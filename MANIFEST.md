# Reproducibility Manifest

This file maps the released materials to the manuscript's data-availability commitments and lists the recomputation entry points.

## 1. Corpus and gold standard

| Material | Path |
|---|---|
| Corpus source list (type, tier, audience, URL, acquisition date) | `data/metadata.csv` |
| Corpus text checksums (SHA-256) | `data/corpus_checksums.sha256` |
| Candidate pool (222 items) | `data/gold_standard/candidate_pool_v3_clean.csv` |
| Gold-standard concepts (131, tier/level/doc_count) | `data/gold_standard/golden_concepts_tiered.csv` |
| Main relation set (75) | `data/gold_standard/golden_relations.csv` |
| Extended relation set (43 + 1 standalone node) | `data/gold_standard/golden_relations_extended.csv` |
| Screening guideline (v2) | `data/gold_standard/screening_guideline_v2.md` |
| Screening records (authors A/B) | `data/gold_standard/screening_full/fullscreen_author{A,B}_done.csv` |
| Adjudication record | `data/gold_standard/adjudication/adjudication_done.csv` |
| Cumulative-coverage curve data | `data/gold_standard/cumulative_coverage.csv` |
| Held-out gold annotations (14 courses) | `data/held_out/heldout_gold_concepts_annotated.csv` |
| Held-out metadata | `data/held_out/metadata_heldout.csv` |
| Third-party audit records | `data/gs_audit/thirdparty_review_*.csv`, `data/gs_audit/audit_results.md` |

Note: the raw syllabus texts are **not redistributed**; obtain them from the corresponding author and place the `.txt` files under `data/raw/` before re-running (see `README.md`).
